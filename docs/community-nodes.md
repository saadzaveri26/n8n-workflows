## How to Install

1. In n8n, go to **Settings → Community Nodes**
2. Click **Install a community node**
3. Enter the npm package name exactly as listed above
4. Restart n8n after installation

---

## Useful Community Nodes (General Reference)

| Package | Description |
|---------|-------------|
| `n8n-nodes-puppeteer` | Full browser automation / web scraping |
| `n8n-nodes-python` | Run Python scripts inline |
| `n8n-nodes-firecrawl` | Clean web scraping with Firecrawl API |
| `n8n-nodes-browserless` | Headless Chrome automation |
| `@n8n-community/n8n-nodes-text-manipulation` | Advanced string/text utilities |
